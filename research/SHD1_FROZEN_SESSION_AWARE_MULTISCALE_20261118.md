## Authentic sessions and fixed target
Only actual sorted, nonoverlapping completed bars whose End-Start equals declared duration; reject invalid OHLC, volume or duplicate clocks. The previous 12 OBSERVED completed bars, not 12 contiguous wallclock hours, form the warmup and range/activity normalization. Never fill gaps. Returns across session breaks are NOT treated as within-session returns: use zero value and a separate causal elapsed-gap feature. Expose within-session bar index capped at four, elapsed gap in hours capped at 72, UTC time-of-day and trailing observed tick activity. No future session calendar used.
For each eligible completed current bar, set a symmetric barrier centered on current Close with offset max(1 integer quote unit, 0.75 × mean high-low range of preceding 12 observed bars including current). Evaluate FIRST observed upper/lower touch in next THREE bars ONLY if their Starts exactly match previous Ends and all end before the same split boundary; otherwise PATH_UNKNOWN. If both touched in one bar, AMBIGUOUS_UNKNOWN (never resolve fill order); if neither, NONE. Embargo for labels is three bar durations across split boundaries. No OHLC bar proves actual intrabar order/fill.

Pre-score population gate for each symbol-resolution pair: H1 TRAIN >=300, CAL >=120, EVAL >=160; M15 TRAIN >=500, CAL >=160, EVAL >=160, using labels that meet source and chronological constraints. Report all eligible/ineligible counts and reasons, per-split support; no model qualification when gate fails and no after-result sample replacement.

## Distinct fixed native C# methods
Identical gated train/cal/eval rows for all models; no outcome data later than TRAIN in any fit. Three-class UP_FIRST/DOWN_FIRST/NONE.
PRIOR: unconditional per-symbol TRAIN counts, Dirichlet strength=12.
BAYES_SESSION_CONTEXT: categorical posterior by current causal return sign, observed within-session phase and current relative volume high/low; shrink toward TRAIN PRIOR with fixed strength=24; report context cardinality, learned posteriors and difference from prior.
OBSERVED_STATE_TRANSITION: conditional class counts for current and previous causally observed volatility regime and session-break class; shrink=24; report state cardinality. It is NOT a hidden Markov model.
QUANTILE_DEPTH2_TREE: nonlinear TRAIN-only split candidates from feature quantiles .20/.40/.60/.80 of six causal features (momentum/range, range ratio, tick activity ratio, session age, elapsed-gap hours, UTC time-of-day). Maximum depth 2, minimum 64 TRAIN observations per leaf, split gain >= max(.005*parent Gini loss,.002*parent N), Dirichlet leaf smoothing 24 to TRAIN PRIOR. Report real root split index/threshold, leaves, CAL and EVAL material probability divergence. A tree with no split is TREE_NOT_LEARNED, never counted as a distinct successful learner.

## Evaluation and uncertainty
Report for TRAIN, CAL and EVAL: exact counts, multiclass Brier and logloss, incremental Brier relative to fixed prior on IDENTICAL rows, model-vs-prior material probability divergence (maximum class difference >.02), learned state/group/tree structure, diagnostic directional proposal counts and per-week counts. Proposal LONG or SHORT only if predicted direction probability >=.55 and exceeds opposite direction probability >=.10; this is a NONFUNDED diagnostic, not a broker order or strategy claim.
For EVAL, group paired incremental Brier by UTC ISO week; report weekly mean improvement, fraction of positive weeks, standard error and 95% normal-reference interval only if >=8 weekly blocks. Because rolling labels overlap, dates shared between symbols and multiple hypotheses are tested, these intervals remain descriptive, not fully dependence-robust significance; no unadjusted p-value or discovery by cherry-picking. At most a descriptive information candidate requires >=8 EVAL weeks, positive lower bound, >=60% positive weeks, CAL not worse than PRIOR and nontrivial (>2%) distinct predictions. Exposed date range is not an independently confirmed validation period. Report source gap rates and cross-class heterogeneity including failures.
