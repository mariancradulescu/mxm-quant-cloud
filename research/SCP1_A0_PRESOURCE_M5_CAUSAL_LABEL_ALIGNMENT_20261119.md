## Reason (pure code inspection, not empirical results)

But the product's single native Core financial engine consumes **real completed M5/M15 features and every later observed quote**; a 15-minute-delayed hypothetical entry label would unnecessarily differ from the executable model's earliest legal next observation. It would train the right probability metric on the wrong policy lifecycle, undermining the OWNER's main scoring question. This is corrected before original empirical opening, using the already available authenticated HXC1 original M5 data, no collection.
