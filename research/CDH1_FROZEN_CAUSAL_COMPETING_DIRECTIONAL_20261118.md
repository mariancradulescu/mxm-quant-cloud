## Competing risks, censors and unknown intrabar order
At current close, set UP and DOWN barriers symmetric around true current Close, with distance max(1 integer source unit,0.75*mean last 12 observed true H-L ranges through t); fixed horizon THREE scheduled bar durations. For next k=1..3: if original next bar starts exactly at expected previous End and bar.End STRICTLY before split-end, observe that bar's High/Low: neither barrier => risk-step NONE (survival); only UP => terminal UP; only DOWN => terminal DOWN; BOTH => terminal AMBIGUOUS competing touch (terminal unknown order). If missing/delayed bar or crossing TRAIN/CAL/EVAL boundary => CENSOR at that point and stop; not an absent touch and not a NONE outcome. If all three contiguous risk steps show neither => terminal NO_TOUCH. At end of source => CENSOR. Each decision remains in original denominator, regardless of outcome. Ambiguous is represented in likelihood by P(UP)+P(DOWN) at that risk step, never retrospectively labeled based on favorable direction. No assumption that censoring is independent of market state; report plausible sensitivity/bounds and do not claim complete-case unbiasedness. Training uses only observed risk steps whose End < corresponding split boundary; no label leaks across train/cal/eval.

## Two mathematically distinct native C# predictive mechanisms + controls (NO retrospective fitting)
A) Causal context pooled Dirichlet competing-hazard estimator: all actually observable at-risk one-step outcomes in TRAIN, prior = unconditional train-only three-class smoothed counts with strength 12; group by current (within-session) momentum sign, current activity above/below observed trailing mean, and session-age <=2 vs mature; group posterior shrunk toward unconditional PRIOR with strength 24. Ambiguous TRAIN events provide *only* class-set {UP,DOWN}; for model A assign prior-proportional fractional class counts, record ambiguity amount and sensitivity caveat, never claim learned true side.
B) Multinomial L2-regularized softmax discrete cause-specific hazard: class NONE reference=0, UP/DOWN coefficient vectors on standardised causal vector [intercept, momentum/range clipped -6..6, range/current trailing ratio clipped, relative tick volume clipped, capped session age, elapsed gap hours, UTC hour phase]. Training includes only TRAIN actually observed step-risk data, with ambiguous likelihood log(pUP+pDOWN); analytical gradient uses conditional UP/DOWN posterior weights for ambiguous rather than inventing a side. 160 fixed batch-gradient iterations with step 0.15, L2=0.02 on non-intercepts; ALL hyperparameters fixed here, not CAL/EVAL tuned. Compare actual coefficient norm and fraction of materially changed EVAL cause probabilities with fixed PRIOR.
Comparator PRIOR: TRAIN-only unconditional hazard for NONE/UP/DOWN. Additional matched simple directional controls: momentum (sign of current/previous contiguous close change) and counter-momentum, and CASH; no hindsight policy selection.

Each model outputs a fixed one-step probability triple (up,down,none) at t. Horizon-3 first-touch cumulative incidence is P_UP=p_up*(1+p_none+p_none^2), P_DOWN analogously, and no-touch=p_none^3. This is a conditional-constant competing-hazard approximation, NOT claim of exact market hazards or broker executable stopping. Model directional diagnostic LONG only if P_UP>=0.30 and P_UP-P_DOWN>=0.10; SHORT symmetric. Thresholds frozen before original evaluation; do not retune if zero proposals. Baseline/simple rules are compared at the SAME eligible decision clocks; score all proposal outcomes with unknowns, not selectively future-observable clocks.
