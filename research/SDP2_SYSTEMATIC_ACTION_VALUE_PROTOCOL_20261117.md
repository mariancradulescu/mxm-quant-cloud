SDP2 instead learns joint LONG/SHORT conditional economic action values using fixed shallow boosted regression trees, weekly expanding fits and a separate recent residual calibration window. This is a distinct prespecified model, not a threshold relaxation or retuning of those studies. CASH has known zero payoff, never learned noise. Does nonlinear pooled multiscale information improve chronological action-value forecasts and a continuous conditional EUR300 book over simpler information sets?

Per scale: last body/range, upper/range and lower/range, close position, 1/4/8-bar return normalized by observed 8-bar RMS return (floor 1bp), directional efficiency, log RMS range, current range/mean previous range, log tick-volume versus prior mean when positive, fraction of expected gaps. ## Targets, fits and frozen complexity
Compute two normalized conditional central LONG/SHORT NET labels and their adverse counterparts, each using actual price-proxy change, declared current-term friction and rollover scenario. Normalize EUR by contemporaneous minimum-volume EUR notional times causal H1 RMS return times sqrt(horizon hours), floor scale 0.0001 of notional. Train four targets jointly; CASH zero.
Every week 27..52: fit on all earlier rows whose outcomes matured before week-start minus 4h, except the latest four complete weeks reserved solely for residual calibration. Refit identical algorithm; no early stopping, parameter search, model selection or period-specific tuning. Each instrument receives equal total training weight. Fixed 16 boosting rounds, learning rate 0.1, trees depth 2, candidate split thresholds training 25/50/75 percentiles, at least 128 rows per leaf, ridge shrinkage 32 pseudo-observations per leaf. Initial weighted target mean. Fit all four fixed variants: FULL; NO_PEERS; NO_ACTIVITY (remove range/volatility/volume scale columns); OWN_PRICE (only H1 body/position/returns/efficiency plus clock/horizon). PRIOR is train-only pooled mean, CASH is zero. All variants reported, no winner promotion.
Calibrate residual empirical distributions on only preceding four embargo-complete weeks, never current outcomes. Retain weekly residual means for uncertainty and residual quantiles (16 fixed midpoint probabilities) for conditional native scenarios. Effective independent blocks=4, uncertainty multiplier=1; not an independent sample claim. Native stress loss includes 3x largest preceding calibration adverse loss plus current frictions, zero diversification/netting credit. This is a scenario, not a loss guarantee.
