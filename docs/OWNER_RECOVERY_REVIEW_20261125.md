# Review of prior economic rejections

The letter describes the reason for review. A is a valid negative result for the exact configuration. B is an incomplete or inconclusive test. C is a demonstrated technical defect. D is insufficient evidence. E is an incorrect interpretation of evidence. F is financial blocking. G is a filter or threshold that needs a comparator. H is a justified optimization question left open. I is a partial favorable result with limited support. J is a properly tested mechanism/configuration that showed no advantage in the evaluated scope.

Apply more than one letter where the evidence shows different failures. H records an untested alternative rather than a cause of the original loss. The opening review gives practical priorities and preserves every original verdict. The [exposure registry](../research/evidence_registry.json) retains run-level scope, statuses and original artifacts for the older studies.
